How to Add This to Wix



  

    
1

    
In the Wix Editor, click Add Elements in the left sidebar.

  

  

    
2

    
Go to Embed Code → Embed HTML and click to place it on the page.

  

  

    
3

    
Click Enter Code in the embed box that appears.

  

  

    
4

    
Paste the code above and click Update. The widget will appear immediately.

  

  

    
5

    
Resize the embed box to roughly 300 × 160 px so the widget has room to display, then drag it into position.

  






  The host name and link update on their own every month — no code changes or logins required. To add a new host to the rotation, contact the Impact Works team.
